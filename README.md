# Responsive-Lci

A responsive website built with modern web technologies.

## Project Overview

This repository contains the "Lakshaya" responsive website, a fully responsive web design that works seamlessly across all devices - desktop, tablet, and mobile.

## Features

- **Fully Responsive**: Layout adapts to any screen size
- **Bootstrap 5**: Modern CSS framework for consistent styling
- **Font Awesome**: Icon library for visual enhancements
- **Custom CSS**: `style.css` and `media.css` for customized styling
- **JavaScript Interactivity**: `javascript.js` for interactive elements
- **Multiple Image Galleries**: Portfolio and project showcase sections

## Project Structure

```
website Lakshaya responsive/
├── index.html          # Main HTML file
├── style.css           # Custom styles
├── media.css           # Responsive styles for different media
├── javascript.js       # Custom JavaScript
├── .gitignore          # Git ignore file
├── Images/             # Project images and galleries
│   ├── top-banner-img1.jpg - top-banner-img7.jpg
│   ├── partner-1.png - partner-4.png
│   └── student_projects/ # Student project showcase
├── bootstrap-5.3.8-dist/ # Bootstrap framework
├── style.css           # Custom styles
└── README.md           # This file
```

## Technologies Used

- HTML5
- CSS3 (with Bootstrap 5 and custom media queries)
- JavaScript (Vanilla JS)
- Bootstrap 5.3.8
- Font Awesome icons

## Getting Started

1. Clone the repository
2. Open `index.html` in any modern browser
3. Customize content as needed
